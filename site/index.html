Turn your AI assistant into an SEO, AEO & GEO auditor.

br-web-seo audits a website or codebase for classic search and AI search (ChatGPT, Perplexity, Google AI Overviews). It scores the site 0–100, then writes a fix report precise enough for another AI session or a developer to apply, as PDF, Word, Excel, CSV or Markdown.

Capabilities

What it does

One skill, 20 focused modes and ~220 checks with stable IDs. Ask in plain language and your agent picks the mode, follows a checklist, collects evidence, and writes the deliverable.

Technical audit

Crawlability, indexing, canonicals, redirects, robots, sitemaps, rendering (SSR vs SPA), Core Web Vitals, security headers.

→ audit + fix report

Content optimization

Search intent, keyword placement, headings, missing subtopics, E-E-A-T. It analyzes first and rewrites only when you ask.

→ content report

GEO / AI search

Is the site quotable by ChatGPT, Perplexity and AI Overviews? Checks AI-crawler access, llms.txt, answer-first structure and entities.

→ audit + fix report

Internal linking

Orphan pages, hub-and-spoke clusters, anchor text, authority flow, and silos.

→ fix report

Local SEO

Google Business Profile, NAP consistency, citations, reviews and local landing pages.

→ audit + fix report

Ranking-drop diagnosis

Traffic fell after a Google update? It works through an evidence matrix built from Search Console reports.

→ diagnosis report

Pre-deploy gate

A go/no-go checklist before release, so a stray noindex or broken canonical never ships.

→ go / no-go

Reports in any format

Every deliverable is Markdown first, then exported to PDF, Word, Excel, CSV or HTML with the bundled zero-dependency exporter.

→ .pdf · .docx · .xlsx · .csv

Keyword research

Seed → expand → filter → cluster by SERP overlap → a keyword map of pillar and spoke pages, plus a competitor gap.

→ keyword map (Excel)

Content briefs

Writer-ready briefs: page type from the SERP, outline, the information gain competitors miss, E-E-A-T needs.

→ content brief

Content audit

Every URL gets a KEEP / REFRESH / CONSOLIDATE / REMOVE verdict from Search Console data, with decay and cannibalisation checks.

→ verdict table

AI crawlers & agents

GPTBot, ClaudeBot, PerplexityBot and more, by purpose. CDN/WAF blocks, agent-friendly pages, AI share-of-voice tracking.

→ audit + fix report
Workflow

How it works

The same five steps every time, so two runs a month apart can be compared line by line.

Scope

Target URL or repo, rendering mode, representative templates, goal, output format.

Audit

Every check records status, where it looked, and the actual evidence. Nothing is assumed.

Score

A weighted 0–100 health score. Any live blocker caps the score at 49.

Report

An audit report (the diagnosis) plus a fix report (the prescription) with code and acceptance criteria.

Gate & export

Pre-deploy go/no-go, then export to PDF, Word, Excel or CSV for your team.

Scoring

A score you can track

Each category is scored out of 10 and weighted. A single live blocker, such as a production noindex, caps the total at 49 however good the rest is. Broken indexing caps it at 20, and any open High issue keeps it below 90. Checks that couldn't be verified are reported as not measured, never as a pass.

FAQ

FAQ

Do I need any API keys or paid SEO tools?

No. The skill works with just an agent and a target. If you have Search Console, PageSpeed Insights or an SEO-tool export, give it to the agent for stronger evidence.

Can it change my code?

Audits are read-only. Fixes are written as a report. Your agent applies them only when you ask, and checks each acceptance criterion as it goes.

Does it work if my AI can't browse the web?

Yes. It asks you to paste the rendered HTML, headers, robots.txt and sitemap, and marks anything it couldn't verify as unverified rather than passing it.

How do I get a PDF or Excel file?

Ask for it, or say which formats you want when you start. Coding agents run the bundled exporter (Python standard library only). Chat apps with code execution can run the same script from the bundle, and without it you get Markdown plus CSV you can import.

How do I update or remove it?

Run the install command again to update. Add --uninstall (or -Uninstall) with the same agent and scope to remove it.

Is it safe to point at any site?

The skill treats page content as data and never follows instructions found in it. See the security policy for scope and how to report issues.
